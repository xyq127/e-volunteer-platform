## 四、开发目的

志愿服务活动的组织与开展长期依赖线下沟通，志愿者组织难以统一管理活动申报与志愿者报名，
志愿者也难以了解活动信息与自身参与情况。开发本软件的目的在于：

1. 为志愿者组织提供志愿活动线上申报、活动分类管理、报名人员管理与报名审核的完整工具；
2. 为平台管理部门提供志愿活动的统一审核入口，把控活动的合规性与可执行性；
3. 为公众提供志愿活动与志愿者组织的展示窗口，并支持志愿者线上注册；
4. 形成志愿活动从申报、审核到报名、开展的全流程数据记录，为志愿服务管理提供数据基础。

## 五、面向领域 / 行业

志愿服务管理、社会公益与社区服务信息化领域，适用于志愿者协会、公益服务中心、社区服务机构、
学校青年志愿者组织等开展志愿服务管理工作的单位。

## 六、主要功能

| 序号 | 功能名称 | 功能说明 |
| --- | --- | --- |
| 1 | 公众门户 | 展示志愿者组织与志愿活动风采，提供志愿者注册与用户登录入口 |
| 2 | 志愿者注册 | 手机号查重校验、填写姓名与密码完成注册，由数据库生成志愿者编号并记录注册日期 |
| 3 | 用户登录与权限控制 | 统一账号认证，按角色进入对应工作台；未登录访问受保护页面自动跳转登录页；跨角色访问返回 403 |
| 4 | 志愿者组织工作台 | 按活动状态统计本组织的志愿活动数量，展示审核中的活动与组织资料 |
| 5 | 志愿活动申报 | 活动名称查重、活动时间与招募人数校验，申报后活动进入审核中状态 |
| 6 | 志愿活动分类管理 | 按审核中、审核未通过、未开始、进行中、已结束分类查询活动，支持查看活动详情与逻辑删除活动 |
| 7 | 活动报名人员查询 | 查询指定活动已报名的志愿者名单，展示志愿者基本信息 |
| 8 | 报名审核 | 通过或驳回志愿者的报名申请，记录报名审核结果与审核时间 |
| 9 | 组织资料维护 | 查询并修改志愿者组织的名称与简介 |
| 10 | 平台管理员工作台 | 统计并展示平台内待审核的志愿活动 |
| 11 | 志愿活动审核 | 查看活动详情，对志愿活动作出审核通过或审核不通过的处理，记录审核管理员、审核时间与审核意见 |
| 12 | 注销 | 清除登录会话与浏览器会话 Cookie，返回登录页面 |

## 七、技术特点

1. **分层架构**：采用 Spring Boot 整合 Spring MVC、Spring Security 与 MyBatis-Plus，
   按控制器层、业务层、数据访问层、实体层分层设计，业务接口与实现分离，职责清晰、便于扩展。
2. **角色权限控制**：基于 Spring Security 实现统一的登录认证与基于角色的访问控制，
   页面资源与接口资源均按角色授权，未登录访问自动跳转登录页，越权访问返回 403。
3. **存储过程实现关键业务**：志愿者注册、志愿活动申报、志愿活动审核、报名审核四项涉及多表写库的业务
   通过 MySQL 存储过程实现，业务规则集中在数据库端执行，保证数据一致性与并发安全。
4. **逻辑删除**：志愿活动、志愿者组织、报名记录等业务数据采用逻辑删除标记，
   删除操作只修改删除标记而不物理删除数据，保证历史数据可追溯。
5. **密码安全**：登录密码采用 MD5 摘要保存与校验，比对时使用恒定时间比较，
   系统不保存、也不在日志中输出密码明文。
6. **数据模型完整**：除志愿活动与报名核心业务外，数据模型还覆盖志愿者、志愿者组织、平台管理员、
   志愿服务签到、志愿培训、志愿者培训情况、志愿活动公告、通知公告、公告附件、志愿秀等业务对象，
   为后续功能扩展预留了数据结构。
7. **开箱可用**：项目提供完整的数据库脚本（建库、建表、存储过程与初始化数据）与可直接运行的构建产物，
   执行数据库脚本并启动程序即可使用，并提供初始化管理员与志愿者组织账号。
