## 三、软件的主要功能（1001 字符，有效字数 985）

本系统面向志愿者、志愿者组织与平台管理员三类角色，覆盖志愿活动从申报、审核、报名、开展、签到到服务时长核算与证明出具的全流程线上管理。公众门户展示志愿者组织与志愿活动风采，提供通知公告、公告附件下载与志愿秀广场；公众可凭手机号查重注册为志愿者，统一账号登录后按角色进入对应工作台，未登录访问受保护页面自动跳转登录页，跨角色访问返回 403。

志愿者端提供个人工作台、活动广场、我的报名、我的档案、消息通知、培训与活动公告、志愿秀与志愿服务证明等功能。活动广场按技能命中比例、球面距离、时间冲突与组织历史参与四个维度计算 0 至 100 的匹配度并降序推荐，附匹配理由；支持一键报名与撤回报名，查看待审核、已通过、候补、未通过等报名状态及服务时长，报名通过后确认参加，逾期未确认自动释放名额并递补候补志愿者；在活动现场使用签到码与定位完成签到签退；系统按已核定累计服务时长自动评定一至五星并展示成长进度，生成含服务明细、星级与校验码的志愿服务证明，支持打印与第三方在线校验。志愿秀支持发布图文分享，门户广场展示并按同一志愿者只计一次规则点赞。

志愿者组织端提供活动申报、活动分类管理、报名人员管理、报名审核、签到与时长复核、服务时长补录、培训管理、活动公告管理、组织资料维护与数据导出等功能。活动申报校验名称重复、活动时间与招募人数，申报后进入审核中状态；报名满员自动进入候补队列，名额释放后自动递补；签到码由签到密钥与时间窗口派生并每 120 秒轮换，更换密钥后旧码立即失效；活动结束结算考勤，记录爽约并扣减信用分；线下服务可补录时长并提交平台复核，导出报名考勤名单与服务时长明细。

平台管理员端提供志愿活动审核、补录时长复核、时长异常裁定、通知公告与附件管理、组织与志愿者账号管理、志愿秀管理与审计日志等功能。活动审核不通过须选择结构化原因，组织修改后可重新申报；服务时长异常由可配置规则引擎自动检出并转人工裁定，命中记录不计入累计时长，裁定为计入或冲销；账号支持开通、启停与密码重置，关键操作全程写入审计日志。

系统通用能力包括：列表统一分页与关键字检索，数据导出为可直接打开的 CSV；站内通知在报名、审核、时长复核、活动公告与活动起止等节点推送并展示未读数；服务对象可用确认码与预留手机号反向确认或否认服务，否认且已计入时长的记录自动冲销；登录密码以加盐摘要存储并支持历史密文平滑升级。

## 四、软件的技术特点

**可选标签（官方 15 项，最多勾选 3 项、至少 1 项）**：
APP、游戏软件、教育软件、金融软件、医疗软件、地理信息软件、云计算软件、信息安全软件、
大数据软件、人工智能软件、VR软件、5G软件、小程序、物联网软件、智慧城市软件。

**本项目建议**：勾选 **云计算软件**（B/S 架构 Web 应用，服务端集中部署、浏览器访问，符合该标签口径）。
不建议勾选「人工智能软件」——本系统的供需匹配是基于技能、距离、时间与历史参与的确定性打分（纯函数、
可单元测试），并非模型推理；也不建议勾选「信息安全软件」，密码加盐与审计日志属本系统的安全实现，
不构成以安全为主业的软件类型。

**描述（82 字符，≤100）**：

基于 Spring Boot 分层架构，关键业务由 MySQL 存储过程在行锁下保证一致性；服务时长由签到码、时间窗口、地理围栏与人工复核共同约束，证明可在线校验。
